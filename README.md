# cultur3.capital static archive

Static export of https://cultur3.capital (Nuxt 3 site, rendered pages captured 30 Sep 2026), served by GitHub Pages.
The Strapi CMS and the EC2/RDS stack behind the original site are retired; images from cdn.cultur3.capital are copied into `cdn/`.
Locale roots (/fr, /jp, /kr, /zh) returned HTTP 500 on the original site and redirect to `/`.
